# Analytics Dashboard Troubleshooting Guide

## Common Issues

### Dashboard Not Loading
**Problem:** The analytics dashboard shows a blank screen or loading spinner.

**Solutions:**
1. Clear your browser cache and refresh the page
2. Check your internet connection
3. Make sure you are logged in with correct credentials
4. Try a different browser

---

### Data Not Updating
**Problem:** Analytics data appears outdated or not refreshing.

**Solutions:**
1. Click the refresh button on the dashboard
2. Check your selected date range is correct
3. Wait 5-10 minutes as data updates every few minutes
4. Log out and log back in

---

### Charts Not Displaying
**Problem:** Charts and graphs are not rendering correctly.

**Solutions:**
1. Make sure JavaScript is enabled in your browser
2. Disable browser extensions that may block scripts
3. Try zooming out your browser to 100%
4. Update your browser to the latest version

---

### Export Not Working
**Problem:** Unable to export analytics data.

**Solutions:**
1. Check your browser allows file downloads
2. Make sure you have selected a valid date range
3. Try exporting a smaller date range
4. Check your internet connection is stable

---

### API Errors
**Problem:** Seeing API error messages in the dashboard.

**Error Codes:**
| Code | Meaning | Solution |
|------|---------|----------|
| 401 | Unauthorized | Re-login to refresh your token |
| 404 | Not Found | Check the content ID is correct |
| 500 | Server Error | Wait a few minutes and try again |

---
