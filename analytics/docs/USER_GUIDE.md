# Analytics Dashboard User Guide

## Overview
The geomesh-protocol Analytics Dashboard helps you track and understand your content performance.

## Getting Started
1. Navigate to the Analytics section from the main menu
2. Select your date range using the date picker
3. View your metrics on the dashboard

## Dashboard Features

### Overview Panel
- Total views and engagement metrics
- Growth trends over time
- Top performing content

### Content Analytics
- Individual post performance
- Engagement rates
- Audience reach

### Audience Insights
- Demographics breakdown
- Geographic distribution
- Device and platform usage

## Filtering Data
- Use the date range picker to filter by time period
- Filter by content type using the dropdown menu
- Export data using the Export button
